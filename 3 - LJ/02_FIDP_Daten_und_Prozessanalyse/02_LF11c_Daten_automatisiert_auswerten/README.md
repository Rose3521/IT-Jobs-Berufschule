# 📈 LF 11c: Daten automatisiert auswerten (FIDP)

> **3. Lehrjahr – FIDP (80 Std.):** Statistische Verfahren, Machine-Learning-Modelle und BI-Werkzeuge einsetzen, um datengetriebene Erkenntnisse und Prognosen automatisiert zu gewinnen.  
> **Status:** 🚧 Grundstruktur angelegt *(wird im 3. Lehrjahr befüllt)*

---

## ✅ Checkliste der Lehrinhalte (Rahmenlehrplan)
- [ ] **Statistische Grundlagen:** Skalenniveaus, Lagemaße (Mittelwert, Median, Modus), Streuungsmaße (Varianz, Standardabweichung, Quartile/Boxplot), Korrelation vs. Kausalität
- [ ] **Automatisierte Auswertung (z. B. Python/pandas, SQL, R):** Skriptbasierte Pipelines, Aggregationen, Zeitreihenanalysen, Anomalieerkennung
- [ ] **Machine Learning (Grundlagen):** Überwachtes Lernen (*Regression, Klassifikation*), Unüberwachtes Lernen (*Clustering*), Trainings-/Validierungs-/Test-Split, Overfitting, Metriken (*Accuracy, Precision, Recall, F1, Confusion Matrix*)
- [ ] **Business Intelligence & Visualisierung:** KPI-Definition, zielgruppengerechte Dashboards (Power BI / Tableau / Grafana), Vermeidung irreführender Diagramme
- [ ] **KI-Ethik & Bias:** Verzerrungen in Trainingsdaten erkennen, Erklärbarkeit (*Explainable AI*) & EU AI Act Grundlagen
