# 🔄 LF 8: Daten systemübergreifend bereitstellen

> **2. Lehrjahr (80 Std. – Rahmenlehrplan AO 2020):** Daten aus heterogenen Quellen zusammenführen, transformieren, über Schnittstellen austauschen und sicher für Anwendungen bereitstellen.  
> **Status:** 🚧 Grundstruktur angelegt *(wird mit fortschreitendem Unterricht & neuen `EduSysTrainings`-Modulen erweitert)*

---

## ✅ Geplante Lehrinhalte & Checkliste
- [ ] **Heterogene Datenquellen & Datenformate:** CSV, JSON (inkl. JSON Schema), XML (inkl. XSD, XPath), YAML, Binärformate & Zeichensätze (UTF-8)
- [ ] **Datenbanken vertiefen:** Komplexe **SQL-Abfragen** (Subqueries, `LEFT/RIGHT JOIN`, Views, Transaktionen / **ACID**, Indizes, Stored Procedures) sowie **NoSQL-Konzepte** (Dokumenten-, Key-Value-, Graph-, Spaltendatenbanken)
- [ ] **Datenintegration & ETL-Prozesse:** *Extract – Transform – Load*, Datenbereinigung, Dublettenerkennung, Validierung und Fehlerprotokollierung
- [ ] **Schnittstellen & Webservices:** **REST-APIs** (HTTP-Methoden `GET/POST/PUT/PATCH/DELETE`, Statuscodes, OpenAPI/Swagger, Pagination), **SOAP/WSDL**, GraphQL, Webhooks
- [ ] **Authentifizierung & Autorisierung an APIs:** API-Keys, Basic Auth, Bearer Tokens / **JWT**, **OAuth 2.0**, CORS, Rate Limiting
- [ ] **Datenschutz & Datensicherheit:** Datenminimierung, Verschlüsselung (TLS), SQL-Injection-Schutz (*Prepared Statements*), Zugriffskontrolle & DSGVO-Konformität beim Datenaustausch
